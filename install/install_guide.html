AP Browser Connect — Extension Installation

One-time manual step (Chrome requires it). Everything else is handled by the installer.

Step 1 — Open the extensions page

  1. Open Google Chrome.
  2. Type chrome://extensions in the address bar and press Enter.

Step 2 — Enable Developer mode

  1. Toggle Developer mode (top-right corner of the page).
  2. The toolbar row with Load unpacked, Pack extension, and Update buttons appears.

Step 3 — Load the extension

  1. Click Load unpacked.
  2. In the file picker, select the extension folder that ships next to this PDF.
  3. The AP Browser Connect card appears in the list. (Optional) Pin it to the toolbar via the puzzle icon.
Multiple profiles: repeat Step 3 in every Chrome profile you want ap-browser to control. The installer detects the extension across all profiles automatically.

Step 4 — Done

  1. That's it. The installer you launched is watching for the extension and continues automatically the moment it appears — no need to re-run it.
  2. If the installer already timed out, just run bash install/install.sh again; it will pick up the extension immediately.

Step 5 — Verify

  1. Run ap-browser ping. Success looks like: {"ok":true,"data":{"pong":true},...}
  2. If prompted, open the extension popup and set a profile label (e.g. Personal, Work).
